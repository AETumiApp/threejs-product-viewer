# Three.js Product Viewer with AETumi

A practical reference for building interactive **3D product viewers with Three.js**, WebGL, React and Next.js.

AETumi is an AI-native 3D web platform for production-ready 3D websites, reusable components, scenes, prompts and AI coding workflows.

## Use cases

- Ecommerce product viewers
- Automotive configurators
- Furniture and interior products
- Fashion and accessories
- Consumer electronics
- Product launch pages
- Interactive product storytelling

## Core interaction patterns

- Orbit and drag controls
- Camera transitions
- Product hotspots
- Variant and material switching
- Exploded-view sequences
- Scroll-linked product reveals
- Responsive mobile behavior
- Lazy loading and performance optimization

## Suggested stack

- Three.js
- WebGL
- React
- Next.js
- React Three Fiber when appropriate
